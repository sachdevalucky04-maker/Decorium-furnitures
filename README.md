

# 🛋️ Decorium Furnitures – Website

Decorium Furnitures is a simple and elegant furniture website created using HTML and CSS.
This project represents my furniture shop and showcases products with a clean and modern design.

---

## 🌐 Project Overview

This website is designed to display furniture products in a visually appealing way.
It focuses on layout design, styling, and responsive structure using only front-end technologies.

---

## 📌 Features

* 🏠 Home Page
* 🛋️ Furniture Product Section
* 🖼️ Product Images Display
* 📞 Contact Section
* 📱 Basic Responsive Design
* 🎨 Clean and Modern UI

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox / Basic Layout Styling

---

## 📂 Project Structure

```
decorium-furnitures/
│
├── index.html

└── images/
```

## ▶️ How to Run

1. Download or clone the repository:

```bash
git clone https://github.com/sachdevalucky04-maker/decorium-furnitures.git
```

2. Open the project folder.
3. Double click on **index.html**
   OR open it in your browser.
